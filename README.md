## 📚 Topics

- **Angular fundamentals** — Angular CLI, components, templates, data binding
- **Directives & pipes** — structural/attribute directives, built-in and custom pipes
- **Component communication** — `@Input`, `@Output`, content projection
- **Forms** — template-driven forms, reactive forms, validation
- **Services & dependency injection** — providers, injection tokens, singleton services
- **HTTP & data fetching** — `HttpClient`, observables, RxJS, loading/error states
- **Routing** — `RouterModule`, route params, guards, lazy loading
- **State management** — signals, services with `BehaviorSubject`, intro to NgRx
- **AI in the workflow** — scaffolding components, explaining Angular patterns, reviewing code (with human validation)

## 🔌 VS Code extensions for TypeScript & Angular

Built-in **JavaScript and TypeScript** support in VS Code covers syntax highlighting, IntelliSense, and Go to Definition. These extensions complement it for day-to-day Angular + TS work:

| Extension                                                                                                                         | Why use it                                                                         |
| --------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| **[Angular Language Service](https://marketplace.visualstudio.com/items?itemName=Angular.ng-template)**                          | Official Angular tooling — template IntelliSense, diagnostics, and navigation.     |
| **[Pretty TypeScript Errors](https://marketplace.visualstudio.com/items?itemName=yoavbls.pretty-ts-errors)**                      | Easier-to-read TypeScript error messages (great while learning).                   |
| **[Prettify TypeScript: Better Type Previews](https://marketplace.visualstudio.com/items?itemName=MylesMurphy.prettify-ts)**      | Nicer hover previews for complex types (generics, nested objects, utilities).      |
| **[ESLint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint)**                                          | Lint `.ts` files with project rules; catches many issues before run time.          |
| **[Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode)**                                        | Consistent formatting; pair with "Format on Save" in settings.                     |
| **[Error Lens](https://marketplace.visualstudio.com/items?itemName=usernamehw.errorlens)**                                        | Shows errors and warnings inline in the editor.                                    |
| **[Path Intellisense](https://marketplace.visualstudio.com/items?itemName=christian-kohler.path-intellisense)**                   | Autocompletes file paths in `import` statements.                                   |
| **[npm Intellisense](https://marketplace.visualstudio.com/items?itemName=christian-kohler.npm-intellisense)**                     | Autocompletes package names when importing from `node_modules`.                    |

*Optional:* **[Import Cost](https://marketplace.visualstudio.com/items?itemName=wix.vscode-import-cost)** shows import size hints (useful when bundle size matters).
