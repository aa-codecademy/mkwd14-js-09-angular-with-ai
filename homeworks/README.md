# Homeworks

This folder holds every homework assignment for the course, one markdown file per homework, named `hmw_N.md`.

Each homework builds on everything taught in class up to that point — check the relevant `class_0N/README.md` files if you need a refresher on a concept before diving in.

## Index

| # | Topic | Based on | Link |
|---|---|---|---|
| 1 | Nestly — an Airbnb-style listings page | Class 1 (components, bindings, control flow, pipes) + Class 2 (content projection, directives, custom pipes) | [hmw_1.md](./hmw_1.md) |

## How to submit

1. Create your solution as a new standalone Angular app (`ng new`) in its own folder alongside the assignment file (e.g. `nestly/`).
2. Make sure `ng serve` runs without errors before submitting.
3. Push your branch/PR (or share your folder, depending on what's agreed in class) before the stated deadline.

> **Note:** Ask in class if anything in an assignment is ambiguous — these are intentionally open-ended on styling and content so you can make them your own.
